# FluxLinux v2.1.8 Release Notes (Ubuntu edition)

### 1. Ubuntu commands broken after `apt upgrade`
- After `sudo apt upgrade`, every basic command in the Ubuntu guest (`ls`, `wc`, `uname`, `env` and the rest of coreutils) could fail with `Security violation: Requested utility … does not match executable name: /.l2s/…`.
- Cause: Ubuntu 26.04 now uses the Rust coreutils, installed as hard links to one program. Android doesn't allow hard links in app storage, so PRoot stores them as links in `/.l2s/`, and Ubuntu's check then refuses every command.
- Broken installs are repaired automatically: before opening a terminal, starting the desktop or running setup, the app points those commands at the GNU coreutils that are already installed.
- Ubuntu setup now switches the guest to GNU coreutils (`coreutils-from-gnu`), so later upgrades can't break it again. On an existing install, re-run environment setup, or run this in the Ubuntu terminal:
  `sudo apt install --allow-remove-essential coreutils-from-gnu coreutils-from-uutils-`

### Migration Notes
- Upgrading from v2.1.x keeps your Ubuntu install and files.

### Checksums
- SHA-256 for both APKs is listed on the GitHub release page. The debug APK is for diagnosis only: it is signed with a debug key, so it can't update a release install.
