# FluxLinux v2.1.1 Release Notes (Ubuntu edition)

### Fix: desktop on Android 17
On Android 17 the desktop never started. The log ended with "Failed to load native library. Did you install the right apk?" and "X server did not create …/X0". Android 17 refuses to load a native library from a file the app can write, and the X server's `libXlorie.so` was being copied into the app's writable data directory.

The X server now loads the read-only copy that Android installs alongside the APK. It also no longer copies the 20 MB library on every first start. The old copy remains as a fallback for devices without the read-only copy. If loading still fails, the error now names the path and the reason.

Upgrading from v2.1.0 keeps your Ubuntu install and files. Uninstall first only if you're coming from the upstream FluxLinux build, because it is signed with a different key.
