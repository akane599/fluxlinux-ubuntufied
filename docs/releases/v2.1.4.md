# FluxLinux v2.1.4 Release Notes (Ubuntu edition)

### 1. Fresh install no longer stalls on the Papirus icon theme
- In v2.1.3 a fresh install could sit for many minutes at "Unpacking papirus-icon-theme". Android's own `tar` can't unpack `.tar.xz` files (it has no `xz`), so the app's attempt failed. After that failure, v2.1.3 also deleted the copies Ubuntu needed to unpack the bundled icons itself, and setup fell back to downloading and unpacking the full Papirus package (100k+ files).
- The bundled theme, icon and cursor archives now always stay available to Ubuntu, which unpacks them in seconds.
- Under PRoot, setup never falls back to the full `papirus-icon-theme` package; if icons are still missing it uses the Adwaita icons. Chroot installs still use the package, without its recommended extras.

### 2. Debug APK
- From this release, each release also ships `FluxLinux-Ubuntu-v<version>-debug.apk`, for diagnosing problems (`adb shell run-as com.ivarna.fluxlinux` works with it).
- It is signed with a different (debug) key, so it can't update an installed release. Uninstall FluxLinux first, which deletes its data. For normal use, install the regular APK.

### Migration Notes
- Upgrading from v2.1.x keeps your Ubuntu install and files.

### Checksums
- SHA-256 for both APKs is listed on the GitHub release page.
