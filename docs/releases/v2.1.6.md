# FluxLinux v2.1.6 Release Notes (Ubuntu edition)

### 1. Session drawer instead of the top bar
- The terminal no longer has a top bar or a tab row, so the terminal area is taller and starts right under the status bar.
- A drawer slides in from the left, like Termux's. It holds:
  - the session list: tap to switch, ✕ to close, long-press for Close / Close other tabs
  - **New Ubuntu session**: long-press it or tap ▾ for Ubuntu root, Ubuntu chroot (when root is available) and the Termux host shell
  - the **Extra keys** on/off switch
  - **Back to home**
- Open it with the new ☰ key at the left of the extra-keys bar, or swipe in from the left edge of the terminal.
- With gesture navigation, the lower-middle part of the left edge opens the drawer instead of going back. Back still works from the right edge and the rest of the left edge.
- While the drawer is open, Back closes it. Opening it hides the keyboard.

### 2. Two-row extra keys
- The extra-keys bar is two rows again. Each row starts with Termux's default keys and continues to the right with the rest: `| ~ _ \ BKSP` and `SHFT Fn INS DEL ENT`. Swipe the bar sideways to reach them.
- On wide screens (landscape, tablets) all 12 columns fit without scrolling.
- Fn still opens the F1–F12 row.

### Migration Notes
- Upgrading from v2.1.x keeps your Ubuntu install and files.

### Checksums
- SHA-256 for both APKs is listed on the GitHub release page. The debug APK is for diagnosis only: it is signed with a debug key, so it can't update a release install.
