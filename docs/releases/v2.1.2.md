# FluxLinux v2.1.2 Release Notes (Ubuntu edition)

### 1. Terminal opens Ubuntu directly
- The distro selection screen is gone. Opening the terminal starts an Ubuntu shell right away, and "+" opens a new Ubuntu tab.
- Long-press "+" (or tap its small arrow) for an Ubuntu root shell, Ubuntu chroot (rooted devices with chroot installed) or the Termux host shell for recovery.
- If a shell can't start, the screen shows the reason and a single "Open Ubuntu terminal" retry button.

### 2. Easier tab closing
- Tabs are wider pills with a large close button on every tab (48dp touch target), not just a tiny X on the selected one.
- Long-press a tab for "Close" and "Close other tabs".

### 3. Hold-to-repeat on the extra keys
- The arrow, backspace and delete keys on the terminal's extra-keys bar repeat while held: they start after 0.4 s and speed up. Ctrl/Alt/Shift apply to the whole hold.

### 4. More zsh plugins in Ubuntu
- Oh My Zsh now loads git, extract, colored-man-pages, copypath, copyfile, command-not-found, fzf, zoxide, fzf-tab, zsh-autosuggestions, zsh-syntax-highlighting and history-substring-search. Up/Down search history by what you've typed.
- New installs get fzf, zoxide and command-not-found from apt and fzf-tab from GitHub. Existing installs upgrade in the background on the next terminal start (network needed).
- Only plugins whose files and tools are present are loaded, so a partial install never prints errors.

### Migration Notes
- Your `~/.zshrc` is only changed if its plugin line is still the FluxLinux default; a backup is kept as `~/.zshrc.flux-bak`. A customized plugin line is left alone.
- Upgrading from v2.1.x keeps your Ubuntu install and files.
