# AkaTerminal v2.2.0 Release Notes

FluxLinux Ubuntu edition is now **AkaTerminal**: a terminal first, with Ubuntu 26.04 behind it.

### Before you update from v2.1.x
- Releases are now signed with a new key, so Android can't update a v2.1.x install in place. Uninstall the old app first, then install this one.
- **Uninstalling deletes the app's data, including the Ubuntu install and its home folder.** Copy out anything you need first (for example to `~/storage/shared`).

### Terminal first
- The app opens on its terminal. The Ubuntu page, Files and Settings are in the terminal's drawer (swipe from the left edge or tap ☰).
- Desktop auto-start is gone; start the desktop from the Ubuntu page when you want it.
- Tap a link in the terminal to open it, also in full-screen apps and in the scrollback.
- Paste key on the extra-keys bar (long-press for the clipboard menu); the Tab key now reads TAB.
- The ongoing notification has **Exit** (closes the terminals and the desktop) and **Hold wakelock** (keeps sessions running with the screen off).
- Fixes for full-screen CLIs such as codex: no more freezes on chroot sessions and no stray characters after exit.

### Optional desktop
- Setup installs a terminal-only Ubuntu by default. Turn on "Also install the XFCE desktop" during setup, or add it later from the Ubuntu page.
- An interrupted or failed desktop install is shown as unfinished with a retry, not as installed.
- If part of the shell setup can't finish (for example offline), setup completes with a warning that says what to re-run.

### Root: chroot runtime
- On a rooted phone (Magisk, KernelSU, APatch) setup offers a chroot runtime next to PRoot; it is noticeably faster. Switch between them in Settings; both installs are kept.
- The Ubuntu user is `akane` in both runtimes.

### New look
- A new dark design (Akane-iro), a black terminal and a new launcher icon.

### Checksums
- SHA-256 for both APKs is listed on the GitHub release page. The debug APK is for diagnosis only: it is signed with a debug key, so it can't update a release install.
