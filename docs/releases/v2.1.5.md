# FluxLinux v2.1.5 Release Notes (Ubuntu edition)

### 1. Termux-style extra keys
- The first two rows of the terminal's extra-keys bar now match Termux's default layout:
  - `ESC / ― HOME ↑ END PGUP`
  - `↹ CTRL ALT ← ↓ → PGDN`
- ↑ sits directly above ↓, with ← and → beside it.
- A third, scrollable row keeps the other keys: SHFT, BKSP, DEL, INS, ENT, `| ~ _ \` and Fn (which still opens the F1–F12 row).
- CTRL and ALT work as before: tap applies to the next key, and long-press locks.
- The bar is now three rows, so the terminal area is a little shorter.

### 2. Steady key repeat
- Held arrows, PGUP/PGDN, backspace and delete now repeat at a constant speed, like Termux: the first repeat comes after 0.4 s, then one every 80 ms.
- For the previous speed-up behaviour, turn on **Settings → Terminal → Accelerate held keys**.

### Migration Notes
- Upgrading from v2.1.x keeps your Ubuntu install and files.

### Checksums
- SHA-256 for both APKs is listed on the GitHub release page. The debug APK is for diagnosis only: it is signed with a debug key, so it can't update a release install.
