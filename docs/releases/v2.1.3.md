# FluxLinux v2.1.3 Release Notes (Ubuntu edition)

This release fixes the findings from a full code audit of the app. It is a reliability and security update with no new features.

### 1. Installs survive rotation and Back
- Rotating the screen, entering split-screen, changing dark mode or pressing Back no longer cancels an install that is running or resets onboarding.
- A finished install is remembered even if you leave before the Done page, so auto-start works the next time.
- Cancel and timeouts now stop the whole install, including tar and apt, so a retry never overlaps a run that is still going.
- A partly extracted Ubuntu is no longer treated as installed; it is re-extracted on the next start.

### 2. Desktop start and stop
- The desktop is only reported ready once it is actually running. If it fails to start, the X server and GPU helper are stopped too.
- Pressing Stop and then Start quickly no longer starts two desktops or kills the new one.
- Turnip/PanVK acceleration no longer resets the XFCE window theme.
- After the app is killed, Android no longer shows stale "Installing…" or "session active" notifications.

### 3. Terminal
- Closing a tab whose shell never started no longer kills the app.
- Closing a tab to the left of the current one keeps the right tab focused and drawing.
- `~/.zshrc` repairs back the file up first and don't write through symlinks.

### 4. Display (termux-x11)
- The X11 screen only accepts control messages from FluxLinux itself, and no longer logs typed text or clipboard contents.
- Large clipboard contents no longer crash the X server or garble keyboard input.
- Typing with the on-screen keyboard no longer stalls the UI.
- A reconnect loop that leaked across desktop sessions is fixed.

### 5. Audio
- PulseAudio now uses a private unix socket instead of the shared 127.0.0.1:4713 port, so another app can't intercept desktop audio.

### 6. Root / chroot (rooted devices)
- Root helpers and BusyBox are staged in a root-owned directory and checked by hash before use. Before this, they were reused from `/data/local/tmp`.
- Starting the chroot desktop no longer switches SELinux to permissive.
- Stopping the chroot desktop keeps `/proc`, `/dev`, `/sys` and `/sdcard` mounted while chroot terminals are open.
- Uninstalling a chroot unmounts and checks everything before deleting, so shared storage can't be deleted by mistake. It also no longer freezes the app.

### 7. Housekeeping
- Unused screens, services and helpers were removed.
- Host bootstrap packaging is reproducible.

### Migration Notes
- Upgrading from v2.1.x keeps your Ubuntu install and files.
- Legacy Debian 13 chroot installs made before setup completion was tracked are set up again on their next start.
- "Uninstall" is no longer offered for customization components.
- The "hide phantom-process warning" choice is no longer included in Android backups.

### Known Issues
- These fixes passed the unit, lint and screenshot checks. They have not yet been tested on a physical arm64 device.
- Chroot root filesystems still live under `/data/local/tmp/chroot*`. Moving them is planned.
